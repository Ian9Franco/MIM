# 🎯 Planning, Objetivos & Backlogs

> **¿Qué es esta carpeta?**  
> Es el centro de mando del proyecto. Si volvés a este repo después de varios meses, **empezá leyendo acá**. Acá está definido qué queremos construir, en qué estado real estamos hoy y qué tarea específica toca hacer a continuación.

## ⚡ ¿Cómo retomar el proyecto en 5 minutos?

1. Mirá **`project-status.md`** para recordar qué está funcionando y probado.
2. Abrí **`whosnext.md`** para ver qué tarea puntual quedó en la pole position.
3. Si necesitás contexto estratégico de la versión, consultá **`ROADMAP.md`**.
