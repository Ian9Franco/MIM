Feature: Intelligent Pack Validation & Environment-Aware Build System

Traducción al español:

“Voy a impedir que el usuario haga boludeces antes de exportar un modpack roto.”

Porque claramente confiar en users es como dejarle una Ferrari a un mapache.

Qué hace

Antes de generar alluser.zip y allhost.zip, MIM valida:

dependencias faltantes
conflictos entre mods
mods mal ubicados por entorno (client/server/both)
librerías huérfanas
configs inválidas
datapacks incompatibles
shaders/resourcepacks mal asociados

Y recién después permite exportar.

No más:

“pasé el pack y explotó todo”

Ahora explota antes, con dignidad.

Cómo implementarlo (sin hacer un ritual satánico)
STEP 1 — Persistir metadata real

Ahora no alcanza con guardar .jar.

Necesitás una entidad por mod:

{
  "id": "sodium",
  "name": "Sodium",
  "version": "mc1.20.1-0.5.3",
  "loader": "Fabric",
  "environment": "client",
  "category": "performance",
  "dependencies": ["fabric-api"],
  "conflicts": ["optifine"],
  "requiredFor": [],
  "projectId": "my-pack"
}

No importa el archivo.

Importa saber qué carajo es.

Ese metadata viene de:

FOMO
Modrinth
CurseForge
metadata inspection local

Tu app necesita memoria, no amnesia.

STEP 2 — Priority Classification System

No clasificar así:

performance = essential

Eso es criminal.

Clasificar así:

environment metadata → source of truth
type → second layer
tags → visual classification only

Orden:

environment > type > tags

Siempre.

Sodium no decide su destino por vibes.

STEP 3 — Validation Engine

Antes de build:

validateProject(project)

y devuelve:

{
  errors: [],
  warnings: [],
  suggestions: []
}

Ejemplo:

errors = [
  "Fresh Animations requires EMF"
]

warnings = [
  "Sodium detected in server pack"
]

suggestions = [
  "Remove unused library: Architectury API"
]

Eso es el cerebro.

STEP 4 — Build Gate

Si hay errores graves:

Build blocked

No export.

No negociación.

No democracia.

Si hay warnings:

Build allowed with warnings

porque a veces la gente quiere vivir peligrosamente.

STEP 5 — Smart Split Export

Generar:

alluser.zip
local + essential
resourcepacks
shaderpacks
config
allhost.zip
server + essential
datapacks
config

Pero ahora validado.

No a ciegas.

Perfecto.

smart downloader

modpack integrity system
