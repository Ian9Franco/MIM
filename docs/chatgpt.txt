# ☠️ Caso 1 — Fabric mod incompatible

Ejemplo:

```txt id="vjq5l5"

```

o:

```txt id="2x04up"

```

* fabric classes,
* mixins,

## SAGE debería inferir:

```txt id="p0nn1w"
Probable Sinytra incompatibility detected.

The mod appears to rely on Fabric internals or unsupported mixins that Connector cannot fully translate to Forge.
```

# ☠️ Caso 2 — Access Widener

MUY común.


```txt id="qlu0o2"

```

```txt id="mk2s74"
This Fabric mod likely depends on Access Wideners unsupported by the current Connector layer.
```


# Paso 2 — Clasificar tipo de crash

Esto NO es:

* dependency crash,
* missing mod,
* mixin failure directo.

Es:

```txt id="i7zk8n"

```

O sea:

# server hang / deadlock / heavy IO stall

# Paso 3 — Ignorar el bait inicial

```txt id="2l9g4j"

```

Pero eso probablemente es:

* síntoma,
* no causa.

Minecraft hace esto MUCHO:
te muestra dónde murió, no quién lo mató.

Como un NPC inútil en una serie policial.
