# 📊 Datos que TWEAK debería leer

## CPU

* modelo,
* núcleos,
* threads,
* frecuencia.

Ejemplo:

```txt id="jlwmfm"
Ryzen 5 5600
6C / 12T
```

---

## GPU

MUY importante.

* modelo,
* VRAM,
* driver,
* integrada o dedicada.

Ejemplo:

```txt id="m7psl5"
RTX 3060 12GB
```

---

## RAM

* total,
* disponible,
* velocidad si querés ir full nerd.

---

## Monitores

* resolución,
* refresh rate.

Porque:

```txt id="h11v84"
1080p 60Hz
```

NO necesita las mismas recomendaciones que:

```txt id="i8m98d"
1440p 240Hz
```
