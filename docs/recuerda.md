# 📝 Ideas para la próxima sesión

Estas son las integraciones y mejoras pendientes para el Minecraft Intelligent Manager (MIM):

## 1. Integración con CurseForge
- Implementar búsqueda y descarga desde CurseForge (vía API de Eternal o similar).
- Permitir alternar entre Modrinth y CurseForge en la barra lateral de FOMO.
- Manejo de IDs de proyecto y slugs compatibles.

## 2. Integración con Collections (Modrinth)
- Sincronización con colecciones personales de Modrinth: [Following Collections](https://modrinth.com/collection/following).
- Botón para "Descargar" directamente a un proyecto.
- Visualización de colecciones como "presets" externos.

## 3. Mejoras de UI de Versiones
- Para Datapacks y otros assets ambiguos, permitir desplegar una lista de versiones disponibles antes de descargar, para elegir manualmente (ej: version 44.44.44).
